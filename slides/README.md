# Slides

Slides of every talk of the workshop, one folder per session in the order of the [program](../SCHEDULE.md#full-day-program). They are added as the speakers make
them available, during and after the workshop, and stay online afterwards.

| Folder | Session |
|---|---|
| `01_process_design/` | From Lab to Industry: Process Design |
| `02_tea_fundamentals/` | TEA Fundamentals: Theory and Practice |
| `03_hands_on/` | Hands-on session with OpenPyTEA: introduction (Why OpenPyTEA?) and wrap-up |
| `04_multi_agent_systems/` | Multi-Agent Systems for Process Design |
| `05_industry_talk_shell/` | Industry talk: feasibility assessment in practice (Shell) |

The slides of the community discussion, if any, are kept with its notes in [discussion/](../discussion/README.md).

## For speakers

- Please provide a **PDF**. The original PowerPoint or Keynote file is welcome next to it but not required.
- Name the file `<session>_<surname>.pdf`, for example `02_tea_fundamentals_ramdin.pdf`.
- Keep files below 50 MB (GitHub's limit is 100 MB per file); compress embedded images or videos if needed.
- Slides are published under the repository's [MIT license](../LICENSE) unless you state otherwise in the file.
  If your slides contain material that may not be redistributed, tell the organizers and we link to it instead.

Send the file to `P.B.Tamarona@tudelft.nl` or open a pull request.
